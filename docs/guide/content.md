# 内容中心

QookiX Launcher 内置 **Modrinth** 与 **CurseForge** 双内容中心，无需打开浏览器，模组、整合包、光影、资源包都能在启动器内搜索、安装和升级。

## 进入内容中心

1. 在左侧导航进入**内容中心**。
2. 顶部选择资源平台：**Modrinth** 或 **CurseForge**。
3. 选择内容类型：**模组 / 整合包 / 光影 / 资源包**。
4. 左侧（或顶部）筛选器可按**游戏版本**与**加载器**过滤，只显示当前实例能用的内容。

::: tip 先选对实例
内容中心的安装目标是你当前选中的实例。装之前确认一下实例的版本和加载器，能避免装完发现不兼容。
:::

## 搜索与筛选

- **关键词搜索**：支持中英文，例如「钠」「sodium」「JEI」。
- **版本筛选**：勾选你的游戏版本，结果会立刻收敛。
- **加载器筛选**：Fabric / Forge / NeoForge / Quilt，与实例保持一致。
- **排序**：按下载量、最近更新等排序，方便找热门和新鲜内容。

点进任意条目可以看到简介、截图、版本历史与依赖关系。

## 安装内容

在条目详情页选择版本后点击**安装**：

1. 启动器会自动检查前置依赖（例如 Fabric API）；
2. 缺失的依赖会一并提示，确认后一起装好；
3. 安装完成后资源进入当前实例对应目录。

::: warning 注意版本匹配
模组的「游戏版本」与「加载器」必须同时匹配实例，二者缺一都会导致启动失败。装完如果进不去游戏，先回到实例设置核对这两项。
:::

### 各类型内容的安装位置

| 类型 | 存放位置 |
| --- | --- |
| 模组 | `<实例目录>/mods` |
| 资源包 | `<实例目录>/resourcepacks` |
| 光影 | `<实例目录>/shaderpacks` |
| 整合包 | 作为独立实例导入 |

## 更新与卸载

- **更新**：在实例的「模组 / 资源」列表中，有更新的条目会显示更新提示，可单个或批量升级。
- **停用**：临时不想用某个模组，先停用它而不是删除，方便排查问题。
- **卸载**：在列表中移除即可，关联依赖不会自动删除，可手动清理。

::: tip 一次只装一个
排查启动崩溃时，一次只加一个模组并启动一次，能最快定位罪魁祸首。
:::

## 下载慢或失败

1. 优先在[设置](./settings)里切换到国内镜像源。
2. 检查下载并发数是否过高导致连接被拒，适当调低。
3. 若使用了代理，确认代理规则没有拦截 Modrinth / CurseForge 域名。
4. 仍然失败时，可在平台网页端手动下载，再放进实例对应的 `mods` 目录。

::: details CurseForge 内容下载受限怎么办？
部分 CurseForge 作者限制了第三方 API 分发。遇到无法在启动器内下载的内容，可到 CurseForge 网页手动下载后放入实例的 `mods` 目录，效果相同。
:::

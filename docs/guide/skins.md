# 皮肤中心

皮肤中心提供 **3D 立体预览**，上传、切换、应用皮肤和切换披风都在启动器内完成，不用再去网页端排队。

## 打开皮肤中心

在左侧导航点击**皮肤**即可进入。

## 使用流程

1. 进入皮肤中心，选择要更换皮肤的游戏账号。
2. 在列表中浏览或搜索皮肤，选中后左侧会实时渲染 **3D 预览**，可旋转查看背面与手臂细节。
3. 满意后点击**应用**。
4. 启动游戏即可看到新皮肤。

## 上传本地皮肤

1. 在皮肤中心点击**上传**。
2. 选择本地 `.png` 皮肤文件。
3. 在 3D 预览中确认效果，点击保存并应用。

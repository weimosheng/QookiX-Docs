# 联机房间

QookiX Launcher 集成了**陶瓦联机（Terracotta）**，通过 NAT 穿透让身处不同网络环境的朋友也能像在同一个局域网里一样联机，通常不需要配置路由器端口转发。

## 开始前

- 所有参与者都安装 QookiX Launcher，并进入同一个**联机**页面。
- 房主需要先确保游戏实例能正常启动（版本与模组一致最省事）。
- 建议所有人的游戏版本、加载器与模组列表保持一致，否则进服会失败。

## 创建房间

1. 在左侧导航进入**联机**。
2. 点击**创建房间**。
3. 选择作为服务器端的游戏实例，设置房间名称与（可选的）访问密码。
4. 房间创建成功后，界面会给出**房间号 / 邀请链接**，把它发给朋友。

房主保持启动器开启，房间就会一直在线。

## 加入房间

1. 进入**联机**页面，选择**加入房间**。
2. 输入朋友给的房间号，或直接打开邀请链接。
3. 若房间设了密码，填写后确认。
4. 连接成功后启动游戏，即可在局域网列表或直接进入服务器中看到房间。

::: tip 名字看不见？
NAT 穿透建立需要几秒到几十秒。若列表中没有出现房间，等一会儿刷新，或让房主重新分享一次邀请链接。
:::

## 网络与穿透说明

| 场景 | 表现 |
| --- | --- |
| 双方网络支持穿透 | 直连，延迟最低 |
| 穿透失败 | 自动转为中转，仍可联机，延迟略高 |
| 严格的企业 / 校园网 | 可能完全无法穿透，建议换用手机热点 |

::: warning 中转模式的带宽
穿透失败走中转时，数据会经由中转节点，延迟和稳定性取决于该节点的网络质量。人数较多时建议房主使用上行带宽充足的网络。
:::

## 常见问题

::: details 房间连上就掉线
先排查模组一致性：任意一方的模组版本不同都会导致断开。可以让房主把实例[导出](./instances)分享给其他人导入，保证环境完全一致。
:::

::: details 联机会不会影响单人存档
不会。联机使用的是服务器端实例的存档，本地其它实例不受影响。
:::

::: details 需要正版验证吗
取决于服务器端的在线模式设置。关闭正版验证时，离线账号也能加入。
:::

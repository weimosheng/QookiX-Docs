# 设置与调优

在左侧导航进入**设置**，可以调整启动器的外观、Java、内存、下载与目录等选项。

## 外观

- **主题**：深色 / 浅色 / 跟随系统。主站与文档的主题偏好会自动同步。
- **语言**：切换界面语言。
- **启动行为**：开机自启、关闭时最小化到托盘等。

## Java 管理

启动器会自动检测系统已安装的 Java，并在版本不匹配时下载合适的 Java。

| 游戏版本 | 需要的 Java |
| --- | --- |
| 1.20.5 及以上 | Java 21 |
| 1.18 – 1.20.4 | Java 17 |
| 1.17 | Java 16 |
| 1.16 及以下 | Java 8 |

::: tip 手动指定 Java
如果你装了多个 Java，可以在实例设置中指定某个可执行文件路径。一般情况下交给自动检测即可。
:::

## 内存分配

在实例设置中调整内存上限，参考[创建第一个实例](./first-instance)中的建议表。

::: warning 32 位 Java 有上限
32 位 Java 最多只能使用约 1.5 GB 内存，务必使用 64 位 Java 玩模组整合包。
:::

## 下载设置

- **下载源**：国内用户建议选择镜像源，速度与稳定性更好。
- **并发数**：默认已按多线程下载优化。若网络不稳或出现连接被重置，适当降低并发数。
- **断点续传**：下载中断后重新尝试会从断点继续，不必从头再来。

::: details 下载一直卡在某个百分比
1. 切换下载源（镜像 ↔ 官方）。
2. 降低并发数后重试。
3. 检查代理 / 防火墙是否拦截了下载域名。
4. 删除未完成的分片文件后重新下载。
:::

## 游戏目录

所有实例默认存放在统一的游戏目录中。可以在设置里：

- 查看当前目录路径；
- 修改目录位置（迁移后需手动移动已有数据，或重新下载）。

::: tip 别放在同步盘
不建议把游戏目录放在 OneDrive、iCloud、坚果云等同步盘内，实时同步会导致存档损坏和磁盘占用翻倍。
:::

## 网络与代理

若身处需要代理的网络环境：

1. 在设置中填写 HTTP / HTTPS 代理地址与端口；
2. 或直接使用系统代理（启动器会跟随系统设置）；
3. 确认代理规则允许访问 Minecraft、Modrinth、CurseForge 与镜像域名。

## 数据与隐私

QookiX Launcher 无遥测、无广告，所有数据只保存在你自己的电脑上。卸载时如需彻底清理，删除上文中提到的游戏目录即可。

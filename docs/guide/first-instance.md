# 创建第一个实例

在 QookiX Launcher 中，**实例（Instance）** 是一套独立的游戏配置：游戏版本、加载器、模组、存档、设置都互相隔离。想玩原版、玩模组、玩整合包，各建一个实例就行。

## 新建实例

1. 打开左侧的**实例**页面，点击「新建实例」。
2. 填写实例名称，例如「1.21 原版生存」。
3. 选择游戏版本：
   - **正式版**：官方发布的稳定版本，日常游玩首选。
   - **快照版**：预览新特性的测试版本，存档不建议长期依赖。
   - **远古版**：Beta / Alpha 等早期版本，启动器会自动处理老版本所需的兼容项。
4. 选择加载器（可跳过，之后再装）：

   | 加载器 | 适合场景 |
   | --- | --- |
   | 无（原版） | 纯原版生存、红石、服务器 |
   | Fabric | 轻量、启动快，主流优化模组（钠、锂等）生态 |
   | Forge | 老牌大型模组，经典整合包兼容性最好 |
   | NeoForge | Forge 的分支，新版本模组的常见选择 |
   | Quilt | Fabric 的分支，兼容大部分 Fabric 模组 |

5. 点击「创建」，等待游戏与依赖下载完成。

::: tip 加载器可以后加
拿不准就先建原版实例。之后在实例的设置里随时可以安装或切换加载器，实例里的存档不会丢。
:::

## 分配内存

创建后建议先设置内存上限，默认值可能偏保守或偏激进。

| 物理内存 | 建议分配给游戏 |
| --- | --- |
| 4 GB | 2 GB |
| 8 GB | 4 GB |
| 16 GB | 6 – 8 GB |
| 32 GB 及以上 | 8 – 12 GB |

::: warning 不是越大越好
分配超过物理内存的 70%，反而会因为系统交换导致严重卡顿。整合包一般 6 – 8 GB 足够，原版 2 – 4 GB 即可。
:::

## 启动游戏

回到实例卡片，点击**启动**。首次启动会：

1. 校验 / 下载游戏本体与资源文件；
2. 检测并准备匹配版本的 Java；
3. 拉起游戏窗口。

下载进度会在界面上实时显示，多线程下载会尽量跑满带宽。

## 找不到游戏目录？

实例的存档、模组、资源包都在该实例的独立目录中。可以在实例设置里点击「打开目录」，或到[设置与调优](./settings)中查看统一的游戏目录位置。

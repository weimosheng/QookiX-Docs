# 皮肤中心

皮肤中心提供 **3D 立体预览**，上传、切换、应用皮肤都在启动器内完成，不用再去网页端排队。

## 打开皮肤中心

在左侧导航点击**皮肤**即可进入。

## 使用流程

1. 进入皮肤中心，选择要更换皮肤的游戏角色。
2. 在列表中浏览或搜索皮肤，选中后右侧会实时渲染 **3D 预览**，可旋转查看背面与手臂细节。
3. 满意后点击**应用 / 使用**。
4. 启动游戏即可看到新皮肤。

## 上传本地皮肤

1. 在皮肤中心点击**上传**。
2. 选择本地 `.png` 皮肤文件（标准 64×64 或 128×128 均可）。
3. 在 3D 预览中确认效果，点击保存并应用。

::: tip 皮肤尺寸
- **64×64**：经典尺寸，兼容性最好。
- **128×128**：高清皮肤，细节更丰富，需要游戏版本支持。

旧版皮肤（64×32）也能上传，但部分细节会缺失。
:::

## 常见问题

::: details 应用后游戏里没变化？
皮肤同步到官方服务器需要一点时间，通常几分钟内生效；另外确认使用的是已登录的正版账号，离线模式无法同步皮肤。
:::

::: details 3D 预览不显示？
确认启动器已联网，且显卡驱动支持 WebGL。可以尝试重启启动器，或在[设置](./settings)中关闭硬件加速后重试。
:::

::: details 能导入披风吗？
披风由官方账号权限决定，启动器只能应用账号已有的披风，无法额外添加。
:::

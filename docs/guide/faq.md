# 常见问题

下面汇总了使用 QookiX Launcher 时最常遇到的问题。如果这里没有你要的答案，欢迎到 [GitHub Issues](https://github.com/weimosheng/QookiX-Launcher/issues) 反馈。

## 安装与启动

::: details 启动时提示缺少运行库？
Windows 请安装最新的 [Visual C++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)；Linux 请参考[下载与安装](./install)中的依赖说明安装 `webkit2gtk` 等库。
:::

::: details 杀毒软件报毒怎么办？
启动器未购买代码签名证书，容易被「未知发布者」规则误报。项目完全开源，你也可以自行从源码构建，或把安装目录加入白名单。
:::

::: details 启动器提示有新版本，需要更新吗？
建议更新。更新会修复已知问题并带来新功能，覆盖安装不会删除你的实例与存档。
:::

## 游戏与实例

::: details 游戏启动后立刻崩溃？
按以下顺序排查：

1. 实例的游戏版本与模组要求的版本是否一致；
2. 加载器（Forge / Fabric / NeoForge / Quilt）是否匹配；
3. 模组的**前置依赖**是否装齐（例如 Fabric API）；
4. 内存是否分配过多或过少；
5. 一次只移除一个模组，逐步定位问题模组。
:::

::: details 装了模组但游戏里看不到？
确认模组被放进了**当前实例**的 `mods` 目录，而不是别的实例；同时检查模组是否处于「停用」状态。
:::

::: details 可以和朋友共用同一个实例吗？
可以。用实例的**导出**功能打包后发给朋友，对方导入即可获得完全一致的环境，联机时最省事。
:::

::: details 存档在哪里？
在实例的独立目录中，可通过实例右键菜单的「打开目录」直接进入。
:::

## 下载与网络

::: details 游戏 / 模组下载很慢？
在[设置](./settings)中切换到国内镜像源，并适当调整下载并发数。若使用代理，确认代理规则没有拦截相关域名。
:::

::: details 下载失败或卡在某一进度？
删除未完成的分片文件后重试；若问题持续，切换下载源或降低并发数。详见[设置与调优](./settings)。
:::

::: details 内容中心搜不到某个模组？
可能是该内容只发布在另一个平台。试试切换到 Modrinth / CurseForge 的另一侧搜索，或检查版本与加载器筛选是否过滤掉了它。
:::

## 皮肤与联机

::: details 换了皮肤但游戏里没变？
皮肤需要同步到官方服务器，通常几分钟内生效；另外离线模式不会同步皮肤，需使用已登录的正版账号。
:::

::: details 联机房间搜不到 / 连不上？
参考[联机房间](./multiplayer)：确认双方模组一致、等待 NAT 穿透建立、或让房主重新分享邀请链接。严格的企业 / 校园网可能无法穿透，建议换用手机热点。
:::

## 其它

::: details 启动器会收集我的数据吗？
不会。QookiX Launcher 无广告、无弹窗、无遥测，所有数据只保存在你自己的电脑上，代码以 GPL-3.0 协议开源。
:::

::: details 支持哪些系统？
Windows、macOS 与 Linux 均有对应安装包，界面与操作基本一致。
:::

::: details 想参与开发 / 贡献代码？
项目在 GitHub 开源，欢迎提交 Issue 与 Pull Request：[weimosheng/QookiX-Launcher](https://github.com/weimosheng/QookiX-Launcher)。
:::
